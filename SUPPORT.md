# Support JSearch

This is a volunteer-maintained software archive. If you find value in this project,
here are ways to support it:

## Non-financial support

### ⭐ Star the repository
Starring helps others discover the project.

### 📢 Share it
- Share on social media
- Mention it in blog posts about software archaeology
- Use it as a teaching example

### 🐛 Report issues
Found a bug? Have a suggestion? [Open an issue](https://github.com/uhuntu/JSearch/issues).

###  Contribute
See [CONTRIBUTING.md](CONTRIBUTING.md) for ways to contribute:
- Improve documentation
- Add tests
- Fix bugs in the reference design
- Translate docs to Chinese

### 📚 Cite it
If you use this in academic work, please cite:

```bibtex
@misc{jsearch-archive,
  title={JSearch: A Software Archive (1999-2002)},
  author={Lin, Hunt},
  year={2026},
  publisher={GitHub},
  howpublished={\url{https://github.com/uhuntu/JSearch}}
}
```
